🤫 Silent Scribe

Air-Gapped Video Transcription with AI Summarization

🚀 Quick Start

1 Install Docker Desktop

Download and install Docker Desktop from docker.com

Mac: Download, install, and launch Docker Desktop. Wait for it to start (you'll see the Docker icon in your menu bar).

2 Open Terminal

Mac: Applications → Utilities → Terminal

Navigate to the Silent Scribe folder:

cd /path/to/silent-scribe
Note: Replace /path/to/silent-scribe with the actual location where you copied the folder.

3 Load the Image

If you received silent-scribe-image.tar.gz, load it:

./load

This takes 5-10 minutes. Wait for it to complete.

OR if building from scratch (30-60 minutes):

./build

4 Start the Application

./start
✅ Open your browser to: http://localhost:7860

5 Stop the Application

When you're done, press Ctrl+C in the terminal.

The container will automatically clean up. No other steps needed!

📝 Using Silent Scribe

Transcribe a Video

  • Drag and drop a video file onto the upload area
  • Choose your settings (or use defaults)
  • Click "Start Transcription"
  • Wait for completion
  • Download TXT, SRT, or VTT files

Generate AI Summary

  • After transcription completes, click "✨ Generate Summary"
  • Wait 30-90 seconds
  • View bullet points and paragraph summary
  • Download summary files
💡 Tip: All your settings are automatically saved for next time!

🔧 Troubleshooting

"Permission denied" when running ./load or ./start

Make the scripts executable:

chmod +x load start build

"Docker is not running"

Open Docker Desktop from your Applications folder and wait for it to start.

Can't access http://localhost:7860

  • Make sure the terminal shows "Starting Silent Scribe"
  • Check that Docker Desktop is running
  • Try refreshing your browser
  • Use http:// not https://

Need more help?

Check the docs/TROUBLESHOOTING.md file for detailed solutions.
